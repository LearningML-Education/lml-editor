# Naive Bayes
Naive Bayes estima probabilidades de clase usando el teorema de Bayes, asumiendo independencia condicional entre caracteristicas dada la clase.

## Hiperparametros
- **Variance smoothing**: Valor pequeno que se suma a la varianza para evitar inestabilidad numerica.
- **Class prior smoothing**: Factor de suavizado aplicado a las probabilidades a priori de clase para reducir sensibilidad al desbalanceo.
