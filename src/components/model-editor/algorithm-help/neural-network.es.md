# Red neuronal
Una red neuronal aprende ajustando pesos internos para reducir el error de prediccion en multiples pasadas sobre los datos.

## Hiperparametros
- **Epochs**: Numero de pasadas completas sobre el conjunto de entrenamiento.
- **Batch size**: Numero de muestras procesadas antes de cada actualizacion de pesos.
- **Learning rate**: Tamano del paso usado para actualizar los pesos durante la optimizacion.
