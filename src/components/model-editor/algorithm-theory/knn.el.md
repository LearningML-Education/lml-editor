# KNN

Το KNN (K-Nearest Neighbors) είναι ένας αλγόριθμος που ταξινομεί νέα δεδομένα κοιτάζοντας τα πιο παρόμοια παραδείγματα.

Φαντάσου ότι έχεις σημεία από δύο κλάσεις: μπλε και πορτοκαλί. Κάθε σημείο είναι ένα γνωστό παράδειγμα.
Αν εμφανιστεί ένα νέο σημείο (πράσινο), το KNN βρίσκει τους **K πιο κοντινούς γείτονες** του (π.χ. K=3 ή K=5) και ελέγχει ποια κλάση εμφανίζεται πιο συχνά.

- Αν οι περισσότεροι γείτονες είναι μπλε, το νέο σημείο ταξινομείται ως μπλε.
- Αν οι περισσότεροι γείτονες είναι πορτοκαλί, το νέο σημείο ταξινομείται ως πορτοκαλί.

Το KNN δεν μαθαίνει έναν σύνθετο τύπο. Μαθαίνει αποθηκεύοντας παραδείγματα και συγκρίνοντας αποστάσεις. Γι' αυτό λειτουργεί καλά όταν παρόμοια δεδομένα είναι κοντά μεταξύ τους.

**Βασική ιδέα:**
Μικρό K = πιο ευαίσθητες αποφάσεις (μπορεί να επηρεάζεται από θόρυβο).
Μεγάλο K = πιο σταθερές αποφάσεις (αλλά μπορεί να χάνει λεπτομέρειες).

## Εμπιστοσύνη (βασική πιθανότητα)

Στο KNN, η εμπιστοσύνη μπορεί να εκτιμηθεί πολύ απλά:

**Εμπιστοσύνη για μια κλάση = (γείτονες αυτής της κλάσης) / K**

Αν K = 5 και οι κοντινότεροι γείτονες είναι:
- 3 μπλε
- 2 πορτοκαλί

Τότε:
- Εμπιστοσύνη(μπλε) = 3/5 = 0.6 = **60%**
- Εμπιστοσύνη(πορτοκαλί) = 2/5 = 0.4 = **40%**

Η πρόβλεψη είναι **μπλε**, με **60% εμπιστοσύνη**.

Είναι ένας καλός τρόπος για εξάσκηση στη βασική πιθανότητα: λόγος, κλάσμα, δεκαδικός και ποσοστό.
