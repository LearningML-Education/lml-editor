# Naive Bayes

Το Naive Bayes είναι ένας αλγόριθμος ταξινόμησης που χρησιμοποιεί **πιθανότητα** για να αποφασίσει ποια κλάση είναι πιο πιθανή.

Ρωτάει:
- "Αν αυτό το παράδειγμα ανήκει στην Κλάση A, πόσο πιθανές είναι αυτές οι ιδιότητες;"
- "Αν ανήκει στην Κλάση B, πόσο πιθανές είναι αυτές οι ιδιότητες;"

Μετά συγκρίνει τα σκορ και επιλέγει την κλάση με τη μεγαλύτερη πιθανότητα.

Η λέξη **"naive"** σημαίνει ότι υποθέτει πως οι ιδιότητες είναι ανεξάρτητες (κάθε ιδιότητα συνεισφέρει ξεχωριστά).
Αυτή η υπόθεση δεν είναι πάντα σωστή, αλλά ο αλγόριθμος δουλεύει πολύ καλά σε πολλές πραγματικές εργασίες.

## Απλή διαίσθηση (παράδειγμα φίλτρου spam)

Φαντάσου ότι θέλουμε να ταξινομήσουμε ένα μήνυμα ως:
- **Spam**
- **Όχι spam**

Και κοιτάμε λέξεις όπως: `free`, `win`, `meeting`.

Αν ένα μήνυμα γράφει "free win", αυτές οι λέξεις είναι πολύ πιο συχνές στο spam, οπότε το Naive Bayes δίνει μεγαλύτερη πιθανότητα για spam.

## Εμπιστοσύνη (βασική πιθανότητα)

Το Naive Bayes υπολογίζει ένα score για κάθε κλάση και μετά μετατρέπει αυτά τα scores σε πιθανότητες.

Για κάθε κλάση κάνει:

**Score(κλάση) = P(κλάση) x P(χαρακτηριστικό1|κλάση) x P(χαρακτηριστικό2|κλάση) x ...**

Μετά κάνει κανονικοποίηση:

**Πιθανότητα(κλάση) = Score(κλάση) / (άθροισμα όλων των scores κλάσεων)**

Βήμα-βήμα (μήνυμα: `"free win"`), με απλές μετρήσεις:
1. Φαντάσου ότι τα δεδομένα εκπαίδευσης έχουν:
   - 10 spam μηνύματα, 10 όχι-spam μηνύματα
   - Στο spam: `free` εμφανίζεται σε 6/10, `win` εμφανίζεται σε 3/10
   - Στο όχι spam: `free` εμφανίζεται σε 1/10, `win` εμφανίζεται σε 2/10
2. Μετέτρεψε τις μετρήσεις σε πιθανότητες:
   - `P(Spam) = 10/20 = 0.5`
   - `P(Όχι spam) = 10/20 = 0.5`
   - `P(free|Spam) = 6/10 = 0.6`
   - `P(win|Spam) = 3/10 = 0.3`
   - `P(free|Όχι spam) = 1/10 = 0.1`
   - `P(win|Όχι spam) = 2/10 = 0.2`
3. Υπολόγισε τα scores κλάσεων:
   - `Score(Spam) = 0.5 x 0.6 x 0.3 = 0.09`
   - `Score(Όχι spam) = 0.5 x 0.1 x 0.2 = 0.01`
4. Άθροισε τα scores:
   - `Total = 0.09 + 0.01 = 0.10`
5. Μετέτρεψε σε πιθανότητες:
   - `P(Spam|μήνυμα) = 0.09 / 0.10 = 0.90 = 90%`
   - `P(Όχι spam|μήνυμα) = 0.01 / 0.10 = 0.10 = 10%`
6. Επίλεξε τη μεγαλύτερη πιθανότητα:
   - Πρόβλεψη: **Spam** με **90% εμπιστοσύνη**.

Γιατί δουλεύει: ο αλγόριθμος συγκρίνει "ποια κλάση εξηγεί καλύτερα το ίδιο μήνυμα" και μετά κάνει επανακλίμακα ώστε οι πιθανότητες να δίνουν 100%.
Οι τιμές των scores μπορεί να είναι μικρές επειδή πολλαπλασιάζουμε πιθανότητες, και αυτό είναι φυσιολογικό.

## Γιατί είναι χρήσιμο

- Πολύ γρήγορο στην εκπαίδευση και στην πρόβλεψη
- Δουλεύει καλά στην ταξινόμηση κειμένου
- Καλό βασικό μοντέλο για να ξεκινήσεις
