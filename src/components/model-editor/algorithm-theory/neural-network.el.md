# Neural network

Ένα νευρωνικό δίκτυο είναι ένα μοντέλο που μαθαίνει μοτίβα συνδυάζοντας πολλούς απλούς υπολογισμούς.

Σκέψου το σαν στρώματα από μικρές μονάδες απόφασης (νευρώνες):
- Το **στρώμα εισόδου** δέχεται τα δεδομένα.
- Ένα ή περισσότερα **κρυφά στρώματα** ψάχνουν χρήσιμα μοτίβα.
- Το **στρώμα εξόδου** δίνει ένα score για κάθε κλάση.

## Απλή διαίσθηση (παράδειγμα ταξινόμησης εικόνας)

Φαντάσου ότι θέλουμε να ταξινομήσουμε μια εικόνα ως:
- **Γάτα**
- **Σκύλος**
- **Πουλί**

Το δίκτυο δεν απομνημονεύει μία συγκεκριμένη φωτογραφία.  
Μαθαίνει μοτίβα όπως άκρες, σχήματα, υφές και συνδυασμούς τους.

## Πώς μαθαίνει (εκπαίδευση)

Κατά την εκπαίδευση, επαναλαμβάνει αυτόν τον κύκλο πολλές φορές:
1. **Forward pass**: η είσοδος περνάει από το δίκτυο και παράγει scores κλάσεων.
2. **Σύγκριση με τη σωστή απάντηση**: υπολογίζεται ένα σφάλμα (loss).
3. **Backpropagation**: βρίσκει ποιες συνδέσεις συνέβαλαν περισσότερο στο σφάλμα.
4. **Ενημέρωση βαρών**: προσαρμόζει λίγο τις συνδέσεις για να μειώσει το μελλοντικό σφάλμα.

Μετά από πολλά παραδείγματα, οι προβλέψεις συνήθως βελτιώνονται.

## Εμπιστοσύνη (βασική πιθανότητα)

Στο τέλος, το μοντέλο έχει ένα score για κάθε κλάση.  
Για να μετατρέψει τα scores σε πιθανότητες που αθροίζουν 100%, τα νευρωνικά δίκτυα χρησιμοποιούν συχνά **Softmax**.

Βήμα-βήμα (παράδειγμα):
1. Scores του στρώματος εξόδου:
   - `Γάτα = 3.0`
   - `Σκύλος = 1.0`
   - `Πουλί = 0.0`
2. Το Softmax τα μετατρέπει σε πιθανότητες:
   - `P(Γάτα) = 84%`
   - `P(Σκύλος) = 11%`
   - `P(Πουλί) = 5%`
3. Επιλογή της μεγαλύτερης πιθανότητας:
   - Πρόβλεψη: **Γάτα** με **84% εμπιστοσύνη**.

Σημαντικό: η εμπιστοσύνη είναι εκτίμηση, όχι εγγύηση.

## Γιατί είναι χρήσιμο

- Μπορεί να μάθει σύνθετα μοτίβα
- Λειτουργεί καλά με εικόνες, κείμενο και ήχο
- Μπορεί να βελτιωθεί πολύ με περισσότερα δεδομένα
